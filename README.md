# GCE 1128 · 구글 공인 교육자 레벨 1·2 한 번에 따기

2026. 11. 28. AI·융합교육 교사연구회 역량강화 워크숍 사이트예요. GitHub Pages로 배포해요.

## 당일 운영 (시트만 고치면 사이트에 바로 반영돼요)
시트: GCE 1128 합격 자랑판 (admin@gegseoul.kr 드라이브)
- **실습계정** 탭: 지역 | 학교 | 이름 | 아이디 | 비밀번호 | 구분 | 짝 — 사람이 늘면 맨 아래 행에 추가해요. 사이트에서 이름을 입력하면 본인 것과 짝꿍만 보여요.
  - 짝꿍은 기본적으로 **행 순서대로 둘씩**(인원이 홀수면 마지막 셋이 한 모둠) 자동 배정돼요.
  - 결석 등으로 바꾸려면 **짝** 열에 짝꿍 아이디(예: `sc050@gclass.ice.go.kr`)를 적어요. 여러 명이면 쉼표로 구분해요.
- **실습링크** 탭: 탭 | 제목 | 주소 | 메모 | 실습 — 행을 추가·수정·삭제하면 "연수 순서 및 실습 자료" 목록이 바뀌어요. 탭 이름이 같은 행끼리 묶여요.
- **자랑판** 탭: 합격 등록이 쌓여요.
참가자는 페이지를 새로고침하면 바뀐 내용이 보여요.

## 구성
- `index.html` — 오늘의 순서, 바로 가기, 응시 전 점검, 실습 타이머, 합격 자랑판
- `config.js` — 자랑판 저장소(Apps Script 웹 앱) 주소와 슬라이드·설문 링크
- `apps-script/Code.gs` — 합격 자랑판 저장소 코드 (구글 시트에 붙여 써요)

## 합격 자랑판 연결하기 (admin@gegseoul.kr 계정으로)
1. 새 구글 시트를 만들어요. 이름은 `GCE 1128 합격 자랑판`.
2. 시트에서 [확장 프로그램] → [Apps Script]를 열고, `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장해요.
3. 오른쪽 위 [배포] → [새 배포] → 유형 선택(톱니) → **웹 앱**
   - 설명: `gce-1128`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. [배포] → 권한 승인 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
5. `config.js`의 `API_URL`에 붙여 넣고 저장하면 자랑판이 켜져요.

코드를 고친 뒤에는 [배포] → [배포 관리] → 연필 → 버전 **새 버전**으로 다시 배포해야 반영돼요.
